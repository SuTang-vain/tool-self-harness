# Systematic Debugging

When fixing a bug:

1. Reproduce the failure before editing code.
2. Read the complete error and inspect relevant code.
3. Identify the root cause rather than patching a symptom.
4. Make the smallest targeted change.
5. Run the failing test, then the full test suite before finishing.
