## 解读（E1 局部零结果）

1. **Q2 稳定性确认**：两个密度/接口编辑在 3 fresh repeat 下都完整保持了可靠任务集
   与聚合——h0 的能力天花板对 <2% 内容的单面编辑是稳健的；
2. **Q3 测量粒度不匹配**：15 次尝试量级下，尝试间 token 方差（约 ±10-20%）压过了
   不到 2% 内容的编辑效应；latency 的改善更可能来自运行间排队差异而非候选本身；
3. **效率轨继续条件**：更大的单面编辑（整节删除级）或方差控制设计（配对种子、
   固定尝试数、更多 repeat），否则 Q3 增量不可测。

本轨不产生 lineage 晋升。
