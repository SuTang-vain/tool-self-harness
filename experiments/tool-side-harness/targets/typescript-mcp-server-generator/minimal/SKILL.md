# Generate TypeScript MCP Server

Create a complete Model Context Protocol (MCP) server in TypeScript with the MCP TypeScript SDK
v2. Initialize a Node.js project with ESM, install the SDK packages and Zod, configure TypeScript,
and implement a server that registers tools with Zod input schemas and handles errors. Choose a
stdio or HTTP transport. Generate production-ready code with type safety, async/await, and
comprehensive error handling.
