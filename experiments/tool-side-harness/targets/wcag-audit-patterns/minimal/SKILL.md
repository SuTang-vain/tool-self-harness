# WCAG Audit Patterns

Audit web content against WCAG 2.2 and remediate violations. Conformance levels: A (legal
baseline), AA (standard), AAA (enhanced). POUR principles: Perceivable, Operable,
Understandable, Robust. Common violations by impact — Critical: missing alt on functional
images, no keyboard access, missing form labels, autoplaying media; Serious: insufficient
contrast, missing skip links, custom widgets, missing page titles; Moderate: missing language
attribute, unclear link text, missing landmarks, improper heading hierarchy. Use semantic HTML
and native elements before ARIA.
