# Task: gw-01-atomic-commits

## Goal

The workspace has pending changes. Commit them following the project's git
workflow practices: each commit must do one logical thing, with a message that
follows the project's convention.

## What you have

Consult the harness documentation available to you (`list_skills` /
`load_skill`) before committing — the conventions live there.

`bash check.sh` reports whether the commit count requirement is met.

## What to produce

Your commits in the workspace repository.
