# Task: gw-03-hygiene

## Goal

The workspace has a staged change that includes a file that must never be
committed. Follow the project's pre-commit hygiene: keep the legitimate change
staged and prevent the problematic file from being included.

## What you have

Consult the harness documentation available to you (`list_skills` /
`load_skill`) before committing — the rules live there.

`bash check.sh` reports whether the problematic file is still staged/tracked.

## What to produce

The repository in a clean pre-commit state.
