# Task: gw-03-hygiene

## Goal

A staged change includes a file that must never be committed. Follow the
project's pre-commit hygiene and commit the legitimate change.

## What you have

Consult the harness documentation available to you (`list_skills` /
`load_skill`) — the hygiene rules live there.

`bash check.sh` reports remaining problems.

## What to produce

The repository with the legitimate change committed and the problematic file
excluded and ignored.
