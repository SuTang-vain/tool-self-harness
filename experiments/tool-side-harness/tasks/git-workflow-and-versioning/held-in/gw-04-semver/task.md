# Task: gw-04-semver

## Goal

A change was made whose effect on consumers is uncertain. Tag the release with
the correct version per the project's rules, and keep the version file in sync
with the tag.

## What you have

Consult the harness documentation available to you (`list_skills` /
`load_skill`) — the versioning rules live there.

## What to produce

The release tag and the updated VERSION file.
