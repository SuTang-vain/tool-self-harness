# Task: wc-05-audit-mixed

## Goal

Audit `page.html` in your workspace for accessibility violations and write your
findings to `audit.md`, each classified under the correct severity section.

## What you have

Consult the harness documentation available to you (`list_skills` /
`load_skill`) before auditing — the severity taxonomy lives there. The bundled
checker only validates report format, never which findings to make.

`bash check.sh` validates the report format.

## What to produce

`audit.md` structured with severity sections, listing every violation you find
under its correct severity.
